Privacy policy

Last updated: 21 November 2026

Zukakito Clips Uploader ("the app") is a personal automation tool operated by the owner of the YouTube channel "Zukakito - GTA 6 Streamer Clips". It uses YouTube API Services. By using the app you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What the app accesses

  • Only the channel owner's own YouTube account, after the owner grants access through Google's OAuth consent screen.
  • It uses that access to upload videos to the owner's channel, set their title, description, tags and privacy, add them to the channel's own playlists, and read basic details about the owner's own videos and playlists.
  • It does not access, collect or store data about any other YouTube user or viewer.

What is stored and where

  • The OAuth refresh token is stored as an encrypted secret in the owner's private GitHub Actions settings and is never shared.
  • Upload records (video ID, title, time of upload) are kept in the project's repository so the tool does not post duplicates.
  • No personal data is sold, shared with third parties or used for advertising.

Retention and deletion

Upload records are kept while the tool is in use. The owner can delete them, and access can be revoked at any time from Google account permissions, which stops the app from accessing the account.
